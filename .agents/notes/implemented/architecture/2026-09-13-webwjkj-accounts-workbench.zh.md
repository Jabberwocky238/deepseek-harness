# Agent Note: webwjkj 账号与工作台

Status: implemented

[English](2026-09-13-webwjkj-accounts-workbench.md) | 中文

## 问题

独立 webwjkj 应用需要验证后的手机身份、可选邮箱和微信绑定，以及可扩展工作台，其中中央上下区域能够显示相同类型的面板。

## 决策

[webwjkj](../../../../packages/bundle/webwjkj/README.zh.md) 使用专用 SQLite 账号数据库，通过 Better Auth 管理会话和验证，通过腾讯云 SDK 发送短信、SMTP 验证邮箱、开放平台网站 OAuth 绑定微信。用户 ID 为 UUID。认证表单仅开放所需操作；跨进程文件锁串行执行验证码验证，唯一索引保证每个用户最多绑定一个微信且每个微信只有一个归属用户。生产环境地址要求 HTTPS。

Dockview 管理浏览器标签、分屏、尺寸调整和布局序列化。浏览器入口具有独立编译配置和产物，不使用官方 Web 组合。初始布局将两个同等的中央工作区置于左右侧栏之间，浏览器按用户保存本地布局和便笺。账号设置仍是独立受保护页面。

## 考虑过的替代方案

**完整接入 code-server。** 它的 VS Code 工作台包括文件系统访问、终端和扩展。这些能力超出了所需的应用面板框架；维护中的 Dockview 包提供所需布局行为，无需维护 VS Code 分支。

**自行实现认证和面板布局。** 自行维护验证码会话、OAuth 状态、可拖拽标签和分隔线行为会重复现有库的能力。应用代码负责服务商适配、开放操作、持久化约束和面板内容。

## 影响

部署需要服务商密钥和已审核的腾讯云与微信应用配置。测试使用真实 Loader、HTTP 服务、Better Auth 和 SQLite，仅替换外部投递与 OAuth 调用；包内 HTML 快照覆盖账号和工作台输出。真实服务投递需要单独的有效凭据验证。独立首页决策继续有效；本决策添加认证功能，不改变官方 Web 应用。
