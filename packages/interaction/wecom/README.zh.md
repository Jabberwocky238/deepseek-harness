# @deepseek-ai/dsh-wecom

[English](README.md) | 中文

## 概述

通过支持长连接的企业微信智能机器人与 Agent 对话。插件运行期间保留文本、图片和文件对话的上下文。显式用户白名单或通配符控制访问，每位群成员使用独立历史。真实接入需要机器人凭据及已配置的模型。

## 使用本包

在提供 Agent、凭据、默认模型、Session、权限预设及附件存储的 profile 中挂载本插件。参见[企微指南](../../../docs/user/guide/wecom.zh.md)及[可选配置覆盖层](../../../apps/cli/config/examples/wecom/cordis.yml)。[配置目录](../../../docs/config-catalog.zh.md#deepseek-aidsh-wecom)定义完整字段。

将 `allowedUsers` 设置为准确用户 ID，或使用 `['*']` 允许所有能访问机器人的用户；空列表拒绝所有用户。获准用户可通过单聊或群机器人交互发送文本、图片、图文混排及文件。单聊历史按用户区分，群聊历史按群及用户区分。插件在每个会话中逐条提交消息，并以“Working…”（`en`）或“正在处理中…”（`zh`）开启回复。生成期间用文本预览更新该回复；最终更新包含该活动区间内最后一条已提交的助手文本。不同会话独立执行。

使用不同条目 ID 和机器人凭据挂载多个实例，可同时运行多个机器人；每个实例独立管理会话和去重。

机器人密钥在激活时解析，更换密钥后需重载插件。插件在提交输入前应用配置的权限预设。可选 Agent 预设提供限定于 Agent 的能力；未配置时使用全局挂载的能力。企微中不提供审批或问答界面。权限请求继续使用组合中配置的策略与应答器。

图片和文件下载共用每条消息的字节预算和接纳期限。下载必须使用直接 HTTPS 链接；本地测试可用回环 HTTP，不接受重定向。SDK 负责解密字节。附件存储在输入 Agent 前验证图片并原样保存文件。失败时返回附件状态；卸载会取消待处理下载。

输入文本和完整回复均受 UTF-8 字节上限约束。超长输入被拒绝；超长回复在上限内以省略号结尾。超时任务取消并结束后才发送超时提示。失败任务返回固定状态，不暴露内部错误详情。

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

每条接纳消息使用固定的流 ID。变化的预览按 `replyIntervalMs` 合并；每条消息同时最多有一个更新等待回执。最终更新丢弃未发送的预览，并结束同一个流。失败尝试和超时会用状态替换暂定文本。推理内容和工具调用载荷不会转发。

企微 SDK 负责认证、心跳、重连和回复确认。插件验证回调数据，串行驱动其拥有的 Agent 活动区间，并从已提交的 Session 事件生成回复。Cordis effect 管理监听器、排队任务及 Agent 释放。

不发布运行时不变量伴随插件：本插件不对外提供独立的 Session 状态投影，相关关系由 Agent 和 Session 不变量负责。传输接纳、顺序及清理由 [Loader 组合测试](tests/loader-composition.spec.ts)验证。

</details>

<a id="model-experience"></a>
## 模型体验

### 接纳的文本输入

#### 模型看到的内容

每个接纳的回调将有序内容作为 `user/message` 写入日志。文本保留 `text.content`；图片和文件转为持久的 `image` 与 `file` 引用。支持视觉的模型接收图片输入。文件引用通过现有请求投影和文件工具转为[可读取的文件句柄](../../llm/llm/README.zh.md)。本插件不添加系统提示词或工具定义。模型输入不包含机器人密钥、附件 URL 与解密密钥、回调头及未使用的载荷字段。

#### Token 影响

接纳的文本、图片输入、文件句柄及累积对话历史消耗上下文 token；拒绝或重复的回调不创建模型请求。

#### KV 缓存影响

普通后续消息追加到现有 Session。其他缓存影响由预设及模型提供方负责。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 会话对应关系及有界的已完成消息去重记录仅保存在进程内。重载后开启新对话；已挂载的 Session 持久化可保留日志，但不会恢复这些对应关系。
- 未实现语音、视频、引用载荷、交互卡片及企微审批应答。文件使用现有文件工具；本插件自身不提取 PDF 或 Office 文档文本。
- 会话数量及待处理消息上限约束运行中的工作。达到会话上限后，需要重载才能接纳新会话。饱和时可能丢弃额外回调而不回复。
- 更新发送失败会记录日志，不重新执行 Agent 或重试该更新；仍会尝试后续文本和最终更新。不提供持久发件箱或恰好一次投递保证。
- 所有会话共享配置的工作目录与能力。历史隔离不代表文件系统变更隔离。
- 真实企微认证和投递需要部署凭据；本地测试使用回环企微服务器及脚本模型。
